## Trust model

Every class, property, constant, signature, link and `file.py:NN` reference in these docs is
checked against the installed package by [`_tools/verify_docs.py`](_tools/verify_docs.py):

```
$ /usr/bin/python3 docs/_tools/verify_docs.py
all 12877 checks passed
```

The checker is itself tested against planted defects — see
[`_work/VERIFICATION.md`](_work/VERIFICATION.md).

**No live UCS Central was available.** Examples requiring a server are marked; the rest were
executed offline against the package. Nothing here claims to have been run against hardware.

The reference and both agent indexes are generated by
[`_tools/gen_reference.py`](_tools/gen_reference.py) — stdlib only, offline, and
deterministic. Edit the script, never its output.

## Regenerating

```bash
/usr/bin/python3 docs/_tools/gen_reference.py    # rebuild reference + indexes
/usr/bin/python3 docs/_tools/verify_docs.py      # gate — must exit 0
```

Both need an interpreter that can import the SDK. `/usr/bin/python3` (3.12) has `six` and
`pyparsing`; the `python3` on `$PATH` may not.

## Known SDK defects

Found and verified while writing these docs. They are documented, not fixed — the SDK source
is untouched.

| Symbol | Status |
|---|---|
| `ucsccoreutils.load_mo` | broken on Python 3.11+ (`inspect.getargspec`) |
| `GenericMo.to_mo` | broken on Python 3.11+ (same) |
| `ManagedObject.show_tree` | always broken (`self.children` does not exist) |
| `ucsccoreutils.write_mo_tree` | always broken (`mo.class_id` does not exist) |
| `extract_mo_tree_from_config_method_response` | always broken (calls the above) |
| `UcscHandle.is_local_download_supported` | broken on 3.13+ (`distutils`); logic also inverted |
| `MethodPropertyMeta.name` | `RecursionError` — getter returns itself |
| `TLS1Connection.connect` | broken on 3.12+ (`ssl.wrap_socket`) |
| `MoPropertyMeta.validate_property_value` | short-circuits; a satisfied `min_length` skips the `pattern` check |
| test suite | 24 of 26 modules import `nose`; uninstallable on 3.12 |

The shipped `ucscsdk_ug.rst` also documents three methods that do not exist. See
[`_work/UG-RST-AUDIT.md`](_work/UG-RST-AUDIT.md).

## Security posture

Two facts to design around, both measured rather than assumed:

- **TLS certificates are not verified** — no CA bundle, `check_hostname=False`,
  `verify_mode=CERT_NONE`, and no SDK option to change it. An active man-in-the-middle is
  not detected. Use a trusted management network.
- **Response XML is parsed with the stdlib parser.** External entities are blocked, so
  classic XXE file disclosure does not apply, but internal entity expansion is performed —
  a hostile server can send a small document that costs a lot of memory.

Details in [internals/architecture.md](internals/architecture.md).
